# Digital Diary — Ξυπνητήρι και ένδειξη μπαταρίας

Η ενημέρωση βασίζεται στο δικό σου αντίγραφο `6d0260d` και βρίσκεται στο branch `feat/alarms-battery` του συνοδευτικού Git bundle.

## Τι προστέθηκε

- Ξεχωριστό εικονίδιο ρολογιού στο κάτω μέρος του μηνιαίου ημερολογίου.
- Έως 24 ανεξάρτητα ξυπνητήρια, τρία ανά σελίδα.
- Καθημερινό ξυπνητήρι ή μία φορά σε συγκεκριμένη ημερομηνία και ώρα.
- Προσθήκη με +, αλλαγή ώρας/λεπτού με +/−, ON/OFF, επεξεργασία πατώντας τη γραμμή, διαγραφή με X και επιβεβαίωση.
- Όταν χτυπά: μεγάλη τρέχουσα ώρα και μόνο «Διακοπή», χωρίς αναβολή.
- Επαναλαμβανόμενη μελωδία για MAX98357A. Η οπτική ειδοποίηση συνεχίζει ακόμη και αν ο οδηγός ήχου αποτύχει.
- Ξυπνητήρι πάνω από τις άλλες οθόνες και επιστροφή στην προηγούμενη οθόνη/πρόχειρο μετά τη διακοπή.
- Αποθήκευση στο ξεχωριστό `/alarms.bin`, μαζί με την κατάσταση χτυπήματος. Τα αρχεία γεγονότων δεν αλλάζουν μορφή.
- Συνεργασία με light/deep sleep και προτεραιότητα της νωρίτερης αφύπνισης.
- Μικρή ώρα, εικονίδιο και εκτιμώμενο ποσοστό μπαταρίας στις βασικές οθόνες.

## Τι έχει ελεγχθεί

Πέρασαν 36 εκτελέσιμα host tests με g++/C++17: οι 30 υπάρχουσες ομάδες και 6 νέες. Καλύπτονται αποθήκευση, επανεκκίνηση ενώ χτυπά, ταυτόχρονα ξυπνητήρια, αλλαγές θερινής ώρας, διακοπή με μη διαθέσιμο ρολόι, σφάλματα αποθήκευσης/ύπνου, επαναφορά πρόχειρου και ο κύκλος ζωής του ήχου με προσομοιωμένο I2S/FreeRTOS. Έγινε επίσης έλεγχος διάταξης από την πραγματική έξοδο του renderer με προσεγγιστική γραμματοσειρά υπολογιστή.

Δεν ολοκληρώθηκε εδώ μεταγλώττιση με το πραγματικό ESP32 toolchain: η αρχική λήψη του Arduino framework απέτυχε σε έλεγχο πιστοποιητικού και, μετά την αλλαγή περιβάλλοντος, η εγκατάσταση PlatformIO δεν ήταν διαθέσιμη. Δεν περιλαμβάνεται προμεταγλωττισμένο firmware. Η μεταγλώττιση παρακάτω είναι υποχρεωτικό επόμενο βήμα. Αφή, πραγματικός ήχος, τάση/ποσοστό και φυσική αφύπνιση απαιτούν δοκιμή στην πλακέτα.

## 1. Εισαγωγή στο υπάρχον project

Αποσυμπίεσε το `digital_diary-alarm-battery-update.zip` σε φάκελο `digital_diary-alarm-battery-update` στην Επιφάνεια εργασίας. Μέσα θα βρεις το `.bundle`, αυτόν τον οδηγό και τον πλήρη κώδικα στον φάκελο `source`.

Στο PowerShell:

```powershell
cd "$env:USERPROFILE\Desktop\digital_diary"
$diaryChanges = git status --porcelain
if ($LASTEXITCODE -ne 0) { throw 'Δεν βρέθηκε το Git project.' }
if ($diaryChanges) { throw 'Υπάρχουν τοπικές αλλαγές. Στείλε το git status πριν συνεχίσουμε.' }

$diaryBundle = "$env:USERPROFILE\Desktop\digital_diary-alarm-battery-update\digital_diary-alarm-battery.bundle"
if (-not (Test-Path $diaryBundle)) { throw 'Δεν βρέθηκε το bundle στην αναμενόμενη διαδρομή.' }
git fetch $diaryBundle feat/alarms-battery
if ($LASTEXITCODE -ne 0) { throw 'Απέτυχε η εισαγωγή του bundle.' }

git merge-base --is-ancestor HEAD FETCH_HEAD
if ($LASTEXITCODE -ne 0) { throw 'Το project έχει άλλες νεότερες αλλαγές. Στείλε το git log --oneline -5 για ενοποίηση.' }
git switch -c alarm-battery FETCH_HEAD
if ($LASTEXITCODE -ne 0) { throw 'Δεν άλλαξε το branch. Στείλε το μήνυμα του Git.' }
```

Αυτό δημιουργεί νέο τοπικό branch `alarm-battery` με τις αλλαγές ήδη σε commits. Το `main` παραμένει διαθέσιμο. Μην αντιγράψεις τον φάκελο `source` πάνω από το project όταν χρησιμοποιείς το bundle.

## 2. Μεταγλώττιση πριν από το upload

Στο ίδιο PowerShell:

```powershell
$diaryPio = "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe"
if (-not (Test-Path $diaryPio)) { throw 'Άνοιξε το PlatformIO terminal του VS Code και τρέξε pio run.' }
& $diaryPio run
if ($LASTEXITCODE -ne 0) { throw 'Η μεταγλώττιση απέτυχε. Στείλε ολόκληρο το πρώτο μήνυμα σφάλματος.' }
```

Εναλλακτικά, από το PlatformIO terminal: `pio run`.

Στείλε το αποτέλεσμα της μεταγλώττισης πριν προχωρήσουμε στη συσκευή.

## 3. Πέρασμα στη συσκευή μετά από επιτυχημένο build

Σύνδεσε την πλακέτα με USB και κλείσε τυχόν ανοιχτό Serial Monitor.

```powershell
& $diaryPio run --target upload
if ($LASTEXITCODE -ne 0) { throw 'Απέτυχε το upload. Στείλε το μήνυμα σφάλματος.' }
& $diaryPio device monitor --baud 115200
```

Δεν χρειάζεται `erase`, `uploadfs` ή αλλαγή partition table. Αυτές οι ενέργειες δεν αποτελούν μέρος της ενημέρωσης. Το συνηθισμένο firmware upload χρησιμοποιεί την υπάρχουσα διαμόρφωση partitions και δεν ανεβάζει νέο filesystem.

## 4. Πρώτη δοκιμή στην οθόνη

1. Επιβεβαίωσε ημερομηνία/ώρα και ότι υπάρχουν τα γεγονότα σου.
2. Πάτησε το εικονίδιο ρολογιού και μετά +.
3. Βάλε ώρα 2–3 λεπτά αργότερα, άφησε ON και αποθήκευσε με OK.
4. Περίμενε χωρίς να αγγίζεις την οθόνη, ώστε να κοιμηθεί.
5. Έλεγξε ότι εμφανίζει τη μεγάλη ώρα και «Διακοπή» στην προγραμματισμένη ώρα. Χωρίς συνδεδεμένο ενισχυτή/ηχείο η οπτική δοκιμή παραμένει δυνατή.
6. Πάτησε «Διακοπή». Επιβεβαίωσε ότι επιστρέφει στην προηγούμενη οθόνη και δεν ξαναχτυπά το ίδιο λεπτό.
7. Δοκίμασε ξανά ενώ γράφεις ένα γεγονός. Το πρόχειρο πρέπει να παραμένει.
8. Έλεγξε την ένδειξη μπαταρίας με USB και μετά μόνο με μπαταρία.

## Ήχος και καλωδίωση

Ο κώδικας ορίζει τις εξής αντιστοιχίσεις, κεντρικά στο `src/platform/esp32/board_pins.h`:

| ESP32 | MAX98357A |
|---|---|
| GPIO15 | BCLK |
| GPIO16 | LRC / LRCLK / WS |
| GPIO17 | DIN |
| GND | GND |

Η τροφοδοσία VIN, η σωστή θέση κάθε αγωγού του καλωδίου SH1.0 και οι έξοδοι του ηχείου πρέπει να επιβεβαιωθούν πάνω στα συγκεκριμένα εξαρτήματα πριν την κόλληση. Τα χρώματα των καλωδίων δεν είναι επαρκής ταυτοποίηση. Το GPIO18 δεν χρησιμοποιείται σε αυτή την έκδοση. Το ηχείο συνδέεται στις δύο εξόδους του ενισχυτή, όχι απευθείας σε GPIO.

Για το επόμενο βήμα σύνδεσης χρειάζεται καθαρή φωτογραφία του MAX98357A με τις επιγραφές των ακροδεκτών και του καλωδίου/πλακέτας. Η πραγματική ακουστική ένταση και η κατανάλωση δεν έχουν μετρηθεί.

## Πώς συμπεριφέρεται

- Καθημερινό ξυπνητήρι που αποθηκεύεται αφού έχει περάσει η ώρα του ξεκινά την επόμενη ημέρα.
- Ένα εφάπαξ ξυπνητήρι που έγινε ληξιπρόθεσμο όσο ήταν κλειστή η συσκευή εμφανίζεται όταν υπάρχει ξανά έγκυρη ώρα.
- Τα καθημερινά που έγιναν ληξιπρόθεσμα την τρέχουσα ημέρα μπορούν να χτυπήσουν μετά την εκκίνηση. Δεν αναπαράγονται χαμένες προηγούμενες ημέρες.
- Στην επαναλαμβανόμενη φθινοπωρινή ώρα το ίδιο καθημερινό πρόγραμμα χτυπά μία φορά ανά ημερομηνία. Αλλαγή της ώρας του δημιουργεί νέο πρόγραμμα.
- Αν πέσει σε ώρα που παραλείπεται την άνοιξη, χτυπά στην πρώτη επανεξέταση μετά το άλμα.
- Όσο υπάρχουν ενεργά ξυπνητήρια, γίνεται επανεξέταση του χρόνου το αργότερο ανά 60 δευτερόλεπτα στον ύπνο. Αυτό έχει πρόσθετο ενεργειακό κόστος έναντι ενός μεγάλου διαστήματος deep sleep.
- Αν αποτύχει η αποθήκευση της διακοπής, ο ήχος σταματά και εμφανίζεται «ΕΠΑΝΑΛΗΨΗ». Η συσκευή δεν κοιμάται ώσπου να αποθηκευτεί η διακοπή. Επανεκκίνηση πριν αποθηκευτεί μπορεί να επαναφέρει το χτύπημα.
- Η μπαταρία μετριέται από GPIO1 με τον υπάρχοντα διαιρέτη τάσης της πλακέτας. Το ποσοστό είναι προσεγγιστικό, όχι μέτρηση κατανάλωσης ή ανίχνευση φόρτισης. Άκυρη τάση εμφανίζει `--%`. Η τάση επηρεάζεται από φόρτιση, ηχείο και φορτίο.
- Μετά από πλήρη απώλεια τροφοδοσίας μπορεί να χρειαστεί ξανά ρύθμιση ώρας, όπως στην προηγούμενη έκδοση. Δεν προστέθηκε εξωτερικό RTC.
