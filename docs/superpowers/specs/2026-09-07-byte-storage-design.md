# Byte Storage Design

## Στόχος

Δημιουργία ανεξάρτητου μηχανισμού ανάγνωσης και εγγραφής δυαδικών δεδομένων, ώστε η εφαρμογή να χρησιμοποιεί αρχεία στον υπολογιστή και LittleFS στην ESP32 χωρίς αλλαγές στον υπόλοιπο κώδικα.

## Αρχιτεκτονική

Το `ByteStorage` θα είναι το κοινό interface αποθήκευσης.

Το `DesktopFileStorage` θα υλοποιεί το interface με αρχεία του υπολογιστή.

Η διαδρομή του αρχείου θα δίνεται στον constructor. Η εφαρμογή θα χρησιμοποιεί:

`data/agenda.bin`

Η διαδρομή δεν θα είναι hardcoded μέσα στο storage module.

## API

Το `ByteStorageError` θα υποστηρίζει:

- `None`
- `NotFound`
- `ReadFailed`
- `WriteFailed`

Το `ByteReadResult` θα περιέχει:

- το αποτέλεσμα της ανάγνωσης
- τα bytes που διαβάστηκαν

Το `ByteStorage` θα παρέχει:

- `read()`
- `write(bytes)`

## Desktop συμπεριφορά

Το `DesktopFileStorage`:

- επιστρέφει `NotFound` όταν το αρχείο δεν υπάρχει
- διαβάζει οποιαδήποτε δυαδικά bytes
- επιτρέπει κενό αρχείο
- δημιουργεί τους απαραίτητους γονικούς φακέλους κατά την εγγραφή
- αντικαθιστά πλήρως το προηγούμενο περιεχόμενο
- επιστρέφει `ReadFailed` ή `WriteFailed` όταν αποτύχει κάποια λειτουργία

## Διαχωρισμός ευθυνών

Το storage module δεν γνωρίζει τίποτα για:

- `AgendaState`
- `AgendaManager`
- CRC32
- κωδικοποίηση ή αποκωδικοποίηση
- backups
- recovery

Το επόμενο `AgendaRepository` θα συνδέσει το storage με το `EventCodec`.

## Δοκιμές

Οι δοκιμές θα καλύπτουν:

- ανάγνωση ανύπαρκτου αρχείου
- εγγραφή και ανάγνωση δυαδικών bytes
- bytes με τιμές `0x00` και `0xFF`
- εγγραφή κενού περιεχομένου
- αντικατάσταση παλιού αρχείου
- αυτόματη δημιουργία γονικών φακέλων
